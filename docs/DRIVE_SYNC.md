# Google Drive সিঙ্ক ও ব্যাকআপ (ধাপ ৭খ + ৮খ)

## Drive-এর কাঠামো
```
Our_Family_Archive/
  FamilyManifest.json     বর্তমান সংস্করণ (revision), কোন ফাইলে আছে, SHA-256, কে লিখেছে
  Members/members.json    সদস্য-তালিকা (সর্বশেষ)
  Approvals/approvals.json  অনুমোদন-অনুরোধ ও ভোট (সর্বশেষ)
  ActivityLogs/log-rNNNNNN-<ডিভাইস>.json   প্রতি সিঙ্কে নতুন History
  FamilyHistory/tree-rNNNNNN-<ডিভাইস>.json  প্রতি সংস্করণের পূর্ণ তথ্য (অপরিবর্তনীয়, কখনো মোছা/বদলানো হয় না)
  Relationships/ Photos/ Documents/   (ধাপ ৯-এর জন্য তৈরি থাকে)
  Backups/family-backup-YYYY-MM-DD.zip[.001 ...][.parts.json]
```
দ্বিতীয় অ্যাকাউন্টে: `Our_Family_Archive_Mirror/Backups/` (শুধু ব্যাকআপ, লাইভ তথ্য নয়)।

## সিঙ্কের নিয়ম
- স্থানীয়ভাবে বদলেছে কিনা বোঝা হয় তথ্যের আঙুলের ছাপ (SHA-256) মিলিয়ে।
- শুধু Drive-এ নতুন → নামায় (আগে SHA-256 যাচাই; যাচাই ব্যর্থ হলে কিছু বসে না)।
- শুধু এখানে নতুন → ওঠায় (পরের সংস্করণ নম্বরে)।
- দুই দিকেই নতুন → **দ্বন্দ্ব**: কিছুই বদলায় না, আপনাকে বেছে নিতে হয়। যেটি বাদ পড়ে সেটি Drive-এ আলাদা ফাইলে থেকে যায়।
- লেখার আগে ও পরে Manifest যাচাই (একই সময়ে দুজন লিখলে ধরা পড়ে)। একই তথ্য আবার ওঠে না (SHA-256 মিলিয়ে)।
- অফলাইনে পরিবর্তন জমে থাকে (কিউ = "এখানে বদলেছে" চিহ্ন); নেট ফিরলে বা অ্যাপ খুললে একবারে ওঠে।
- নতুন ফোনে: লগইনের পর Drive থেকে পরিবার খুঁজে সদস্য-তালিকায় আপনার Gmail আছে কিনা **ফোনে বসানোর আগেই** দেখা হয়। না থাকলে কোনো তথ্য নামে না।
- Drive-এ Editor হওয়া মানেই অ্যাপে Admin নয়: অ্যাপের Role ও অনুমোদন-নিয়ম ডেটাবেস ট্রিগারে বাধ্য।

## ব্যাকআপ
- ZIP (JSON + GEDCOM + README + SHA-256) → চাইলে N MB অংশে ভাগ (`.zip.001`, `.002` ... + `.parts.json`)।
- প্রতিটি অংশ আপলোডের পর ফেরত নামিয়ে SHA-256 মিলিয়ে দেখা হয়।
- অংশ জোড়া: অ্যাপে "সব অংশ একসঙ্গে বেছে নিন", অথবা অ্যাপ ছাড়াই: `cat family-backup-DATE.zip.[0-9][0-9][0-9] > family-backup-DATE.zip`।
- পুরোনো ব্যাকআপ: শেষ ৩০ দিনের সব; তার আগের প্রতি মাসের শেষটি। চেনা যায় না এমন নামের ফাইল কখনো মোছা হয় না।

## পরিচিত সীমা
- বাস্তব Google-এ এখনো পরীক্ষা হয়নি (এই পরিবেশে নেট নেই); নকল Google/Drive সার্ভারে পুরো লজিক পরীক্ষিত (tests/cloud.test.ts)।
- `drive.file` স্কোপে অন্য সদস্যের ফোন মালিকের তৈরি ফোল্ডার নিজে থেকে দেখতে পায় না (Google Picker দিয়ে ফোল্ডার খুলতে হয়)। Picker এখনো যুক্ত হয়নি। মালিকের নিজের নতুন ফোন (একই Gmail) ঠিক কাজ করে।
- সিঙ্ক = পুরো তথ্যের সংস্করণ; রেকর্ড-ধরে স্বয়ংক্রিয় মেশানো (merge) নেই।
- অটো-ব্যাকআপ অ্যাপ খোলার সময়/নেট ফেরার সময় চলে (অ্যান্ড্রয়েড ব্যাকগ্রাউন্ডে চালাতে দেয় না)।
- refresh token অ্যাপের নিজস্ব সংরক্ষণে থাকে (এনক্রিপ্টেড কী-স্টোরে নয়)। approvals_required সেটিং এখনো সিঙ্ক হয় না।
