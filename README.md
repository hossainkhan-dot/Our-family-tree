# Family Legacy Archive (বংশ স্মৃতি সংরক্ষণাগার)
২০০ বছর টিকিয়ে রাখার লক্ষ্যে Local-first পারিবারিক ইতিহাস সংরক্ষণ সফটওয়্যার।
আসল ডেটা খোলা ফরম্যাটে (JSON/GEDCOM), অ্যাপ বদলযোগ্য।

    npm install && npm run dev
